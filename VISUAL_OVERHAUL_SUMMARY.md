## Technical Details

### Self-Contained
- **Single HTML file** - No external dependencies except D3.js v7 CDN
- **Embedded data** - All threat model data embedded as JSON
- **No build step required** - Open directly in browser

### Performance
- **Force-directed layout** with proper collision detection
- **Optimized rendering** with D3.js v7
- **Smooth 60fps** animations
- **Lazy particle creation** (only 70% of edges get particles)

### Browser Compatibility
- Modern browsers (Chrome, Firefox, Safari, Edge)
- CSS backdrop-filter support required for glassmorphism
- Responsive design with media queries
